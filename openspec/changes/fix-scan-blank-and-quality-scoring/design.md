## Context

当前预检以 PDF 对象层事实分类页面。对纯扫描 PDF，整页图片的 `image_area_ratio=1.0` 只说明载体是图片，不能证明页面包含有效内容；Docling 又可能把单个污点输出成一字符 block。转换循环随后把任何扫描/混合页面加入低质量集合，并将未达到最低字符阈值的页面加入失败集合。因此近空白页同时污染页面路由、blocks、失败页和总分。

## Goals / Non-Goals

**Goals:**

- 在无需远程模型的情况下，高置信度识别只有微小孤立扫描噪声的页面。
- 保留不确定的稀疏页面，避免把短标题、公式、印章或小图误删。
- 阻止已确认噪声页的伪文字和伪表格进入下游。
- 让质量评分基于有效内容页及实际质量缺陷，而不是页面来源类型。
- 保持现有 JSON 消费者兼容，并提供可审计的新增指标。

**Non-Goals:**

- 不解决一般公式 OCR、目录乱码或页眉标签误判。
- 不修改 chunk/index/retrieve 的公开契约；转换器通过不输出噪声 block 保证下游自然跳过。
- 不引入远程服务，不将近空白检测依赖于 GUI API。

## Decisions

### 1. 使用本地像素与区域联合判定

页面在低文本、图像承载场景下按较低分辨率渲染，计算深色前景像素占比，并通过连通区域统计最大区域、显著区域数和有效内容包围盒。只有前景占比极低、没有显著区域、没有真实表格结构且候选文字仅为极小孤立 block 时，才自动分类为 `scan_noise_only`。

只按字符数判空白会误伤短标题和公式；只按白色像素比例又可能误伤小印章。联合判定更保守，所有阈值集中为常量并由测试覆盖。

### 2. 在 OCR 和表格路由之前确认噪声页

预检仍负责廉价对象层检查；转换循环在 Docling 页面投影已知后，仅对低有效文本的扫描候选执行一次本地渲染判定。确认后清空该页检索 blocks、跳过 RapidOCR、跳过矢量表格和视觉增强，并覆盖 Docling 的单字符误报。

被抑制的文字以 `blank_review.suppressed_text` 和原因保留，不作为 `BlockRecord` 输出。

### 3. 将页面状态与审核状态分离

`page_type` 和 `routing_type` 均允许 `scan_noise_only`；该状态不是失败，也默认不需要人工复核。`intentional_blank_pages` 保留给已有远程确认路径，新增 `scan_noise_only_pages` 表示本地确定性检测结果。

### 4. 质量评分使用有效内容页分母

有效内容页数为 `page_count - intentional_blank_pages - scan_noise_only_pages`。评分由以下实际缺陷扣分：

- 内容页失败比例；
- 内容页低质量比例；
- 表格无效及需复核比例；
- 页眉复核未解决比例。

扫描页数量作为来源统计，不直接扣分。成功通过 Docling/RapidOCR 恢复的扫描页计入 `successfully_recovered_ocr_pages`，只有出现明确警告、编码异常、OCR 不足或失败时才进入低质量集合。

### 5. 兼容性采用附加字段

`PageRecord` 新增前景和连通区域摘要；`QualityReport` 新增噪声页、有效内容页及 OCR 恢复统计。现有字段不删除。原先远程空白复核保持可用，但本地高置信度判定优先避免无必要网络调用。

## Risks / Trade-offs

- [阈值过宽导致小内容被过滤] → 只自动接受极低前景占比且无显著区域的页面；边界样本保留为正常/待复核，不自动删除。
- [不同扫描底色影响阈值] → 使用灰度分位/固定深色阈值组合，并在真实第 14 页与合成灰底页面上验证。
- [额外渲染增加耗时] → 仅检查低文本扫描候选，并复用该渲染结果进行 OCR；正常正文页不增加渲染。
- [旧质量分数不可直接横向比较] → 保留详细分项指标，明确新分数代表有效内容页质量；测试固定新公式。

## Migration Plan

1. 先加入失败回归测试和 OpenSpec 严格校验。
2. 实现本地判定、状态字段和评分函数。
3. 运行单元测试与完整 PDF 转换测试。
4. 重新转换当前 200 页样本，确认第 14 页不产生 block/table/失败记录，并对比评分分项。
5. 如出现误判，可关闭新增选项回退到原路径；JSON 新字段为附加字段，不要求下游迁移。

## Open Questions

- 当前阈值以规范扫描件和本次真实样本为基准；后续可通过更多空白页/稀疏页基准集校准，但不阻塞本次修复。
