# Design

## Decisions

- Use AGPL-3.0 as selected by the user; obtain the complete license from the installed Ultralytics distribution and verify it against GitHub's canonical license text.
- Apply the project license to original code. Preserve third-party rights for dependencies, model assets and PDF references in a separate notice.
- Review all reachable history blobs for common secret patterns, inspect credential-like matches and verify that local settings and user databases remain ignored.
- Publish the license and documentation before changing visibility. Verify the repository ID, public visibility, license recognition, anonymous access and remote commit after publication.

## Scope

The existing repository remains `k1711019707-alt/structural-damage-analysis-agent`. No history rewrite, runtime change or upload of ignored local data is required.
