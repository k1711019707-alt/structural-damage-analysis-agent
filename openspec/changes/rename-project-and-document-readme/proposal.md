# Proposal

## Why

The repository lacks a root README and its GitHub name was accidentally changed to `-Agent`. Users need an accurate introduction and a repository identity matching the structural damage analysis application.

## What Changes

- Add a Chinese README titled `结构损伤智能分析Agent`, grounded in the current model, desktop workflow, RAG implementation and command-line interfaces.
- Document setup, Git LFS, local data exclusions, API configuration, human review, tests and deployment limitations.
- Rename the existing private GitHub repository to an ASCII slug selected with the user and update the local `origin` URL.

## Capabilities

No application behavior or specification requirements change. This documentation and repository-metadata change uses `skip_specs: true`.

## Impact

The root README, this OpenSpec change record, GitHub repository metadata and the local Git remote are affected. Runtime code, credentials, models and user data are outside the change.
