## Context

主项目通过 `models/best.pt`、`YoloSegmentationRuntime`、GUI 识别工作线程和 PyInstaller 资源清单提供损伤识别。新交付物是带 P2 检测层的 8 类 YOLO11s 分割权重；交付目录还包含训练脚本和训练参数，但脚本使用另一台机器的绝对路径。主项目必须在源码、冻结程序和复现入口中保持单一正式模型，并在迁移完成后独立于交付目录运行。

## Goals / Non-Goals

**Goals:**

- 把新 P2 模型复制到项目内并作为唯一正式模型。
- 保持现有 `damage-finding.v1`、GUI、报告和方案链路兼容。
- 保存可移植的 P2 架构和训练入口，不保留外部绝对路径。
- 通过模型完整性、真实 GPU 推理、GUI 调度和打包资源测试后移除旧权重。
- 消除 GUI 工作线程信号处理中的事件循环重入，防止流式生成期间原生栈持续增长。

**Non-Goals:**

- 不复制新训练数据集到主项目。
- 不重新训练模型或宣称独立测试集质量已经提升。
- 不改变面积比例初筛、裂缝像素测量或人工复核规则。

## Decisions

### 使用稳定的产品路径完成原位替换

新权重仍使用 `models/best.pt`。该路径已经由 GUI、CLI、打包 spec 和复现脚本共同使用，原位替换可以避免增加候选模型搜索或运行时回退。旧文件在替换前备份到项目外的工作区 `artifacts`，新链路通过后项目内只保留新权重。

### 清单同时约束文件完整性和模型语义

`deployment/models/model_manifest.json` 记录新文件大小、SHA-256、架构、类别和训练摘要。启动/打包验证继续校验文件大小和哈希；真实模型加载验证任务类型为分割、类别数为 8，并检查类别名称和 P2 stride 4 输出层。

### 保留通用运行时，替换模型实现

`YoloSegmentationRuntime` 是模型适配器和结构化结果生产者，不属于旧模型实现。它继续负责掩膜处理、类别解析、面积测量、裂缝几何、provenance 和 GUI 输出。迁移仅替换其默认模型及相关训练/部署元数据。

### 将训练代码改造成项目内可维护入口

从交付脚本保留 P2 架构、960 输入、mask ratio 2、余弦学习率等关键配置；路径由项目根目录解析。P2 架构 YAML 放入 `configs/`，训练入口复用项目已有的可配置 CLI。默认继续训练使用项目内正式权重和项目现有数据集，不依赖原交付目录。

### GUI 更新依赖 Qt 排队信号而不嵌套泵送事件

识别、报告和施工方案工作线程已经通过 Qt signal 把更新排入 GUI 线程。GUI 槽函数只更新控件并返回，由外层 Qt 事件循环继续分派下一条信号；不得在这些槽函数中调用 `QApplication.processEvents()`。这样既保留流式预览，也避免后续排队信号在当前槽返回前递归进入，造成 Qt6Gui 原生栈溢出。

旧手动报告/方案入口仍同步运行于 GUI 线程。该入口收到文本时直接更新预览并同步重绘预览控件，不处理整个 Qt 事件队列；自动工作流继续依赖后台线程信号和主事件循环完成正常绘制。

## Risks / Trade-offs

- [少数类别样本较少] → 保留模型指标边界，不把接入成功表述为全部类别质量提升。
- [新 P2 模型在 1280 推理时延增加] → 使用真实 GPU 单图和批量冒烟记录推理设备与时延，GUI 继续允许集中配置推理尺寸。
- [二进制覆盖造成回滚困难] → 覆盖前按旧 SHA-256 生成项目外备份；完成后清单和 OpenSpec 记录新 SHA-256。
- [训练脚本来源包含绝对路径] → 只迁移算法配置和架构，最终扫描代码/配置/打包文件中的交付目录字符串。
- [流式增量密集触发 GUI 重入] → 禁止生产槽函数主动调用 `QApplication.processEvents()`，并用排队更新回归测试验证下一次回调只能在当前回调返回后执行。

## Migration Plan

1. 记录并备份旧 `models/best.pt`，校验新源模型哈希。
2. 将 P2 架构和可移植训练配置写入项目。
3. 把新权重复制到稳定产品路径并更新模型清单。
4. 运行契约测试、真实 GPU 推理、运行时结构化输出和 GUI 工作线程测试。
5. 验证 PyInstaller/reproduction bundle 均只包含项目内新权重。
6. 扫描并清除交付目录引用，确认项目内无旧权重或旧哈希。

旧模型仅能通过工作区 `artifacts` 中的迁移备份手工恢复；运行时不提供自动回退。

## Open Questions

无。正式模型路径、8 类顺序和现有结构化输出契约均保持不变。
